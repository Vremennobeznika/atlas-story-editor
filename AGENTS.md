# AGENTS.md — АТЛАС: сценарная мастерская

## Архитектура и ограничения
Автономное браузерное приложение без сервера и обязательной сборки. Данные проектов хранятся локально. Не добавлять удалённую передачу пользовательских данных и внешние зависимости без отдельного согласования.

## Сохранность данных
- Публичный ключ localStorage: `atlas-public-demo-v2`. Не мигрировать и не удалять данные молча.
- Перед потенциально разрушающим импортом обязательно сохранять возможность резервного экспорта JSON.
- Нельзя включать в коммиты экспортированные реальные проекты или персональные данные.
- Контролировать совместимость сериализации, ID, связей, undo/redo и ограничений импорта.
- Изменения модели данных требуют негативных тестов повреждённых входов и проверки round-trip export→import.

## Проверки
1. Прочитать README.md и текущий код до изменений.
2. Выполнить локальные синтаксические и функциональные тесты, доступные в репозитории.
3. Для интерфейса выполнить `node tests/browser-qa.cjs` при работающем локальном сервере на 127.0.0.1:8765 и установленном Chromium Playwright; сценарий CI описан в `.github/workflows/browser-qa.yml`.
4. Проверять основные операции: создание, редактирование, удаление, undo/redo, автосохранение после reload, экспорт, импорт, ошибочные JSON, переключение представлений и горизонтальный overflow на мобильной ширине.
5. Safari/iOS и реальные устройства не объявлять протестированными по результату Chromium.

## Готовность работы
Предоставлять SHA, список изменений, команды, реальные exit codes, результаты E2E, остающиеся риски и ссылку на CI. Пока соответствующие тесты не прошли — BLOCKED. Не заявлять READY только по чтению README или наличию workflow.
