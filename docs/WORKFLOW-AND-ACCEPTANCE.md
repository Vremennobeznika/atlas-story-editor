# Контур приёмки и передачи работы

Источник метода: аудит вложенных агентных навыков (.claude.zip, claude-handoff.zip, test-engineer.md, docs-updater.md), не слепое копирование стороннего кода.

| ID | Контроль | Доказательство | Текущий статус этого изменения |
|---|---|---|---|
| AT-01 | Предыдущий JSON корректно импортируется | тестовый fixture и браузерный лог | NOT VERIFIED |
| AT-02 | Ошибочный/неполный JSON отклоняется без потери текущего проекта | тест и дамп до/после | NOT VERIFIED |
| AT-03 | Undo/Redo/граф и карточки непротиворечивы | browser-qa log | NOT VERIFIED |
| AT-04 | Сохранение и восстановление после перезагрузки | скриншот/тест | NOT VERIFIED |
| AT-05 | XSS на недоверенных названиях/описаниях отсутствует | воспроизводимый тест | NOT VERIFIED |
| AT-06 | Mobile/Safari и accessibility | матрица устройств | NOT VERIFIED |
| AT-07 | Права и персональные данные | проверка diff/контента | NOT VERIFIED |

Тесты этого документального изменения не запускались. Существующие оценки READY/PASS не наследуются автоматически. Отдельно хранить минимум: исходный SHA, ввод, сделанные изменения, команды+коды завершения, блокеры, следующий проверяемый шаг.

Правило резервирования: экспорт JSON до импорта данных, проверка валидности, отсутствие молчаливого перезаписывания. Модификация формата требует миграции и теста отката.
